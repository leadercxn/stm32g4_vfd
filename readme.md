# STM32G474 开发板调试三相变频器项目

1. 工程使用 `Makefile + GCC` 工具链进行工程编译，烧录
2. 工程目录结构
```
    |-- app
    |-- dh_sdk
```

3. 编译
```sh
    make
```

4. 烧录
```sh
    make flash
```

# 硬件
1. U7-74HC244D , 输入输出同高同低
2. U3-74LVC06A , 输入取反到输出
3. 电压公式转换（举例）：  IU * 3/4 = ADCA2   =====> ADCA2 * 4 / 3 = IU = A2adc / 4095 * 3.3 * 4 / 3
    3.1. 用正点原子的驱动板： IU = A2adc / 4095 * 3.3 * 4 / 3 = Ii * 0.12
         ===> Ii = A2adc / 4095 * 3.3 * 4 / 3 / 0.12
4. DSP_EPWMxA, DSP_EPWMxB 到 Px+ , Px- 的电平是相反的

# 数据储存
1. Flash  -- 运行日志
    1.1.  数据结构
        ```C
            typedef struct
            {
                ...
                ...
            } __attribute__((__packed__ )) running_log_t;
        ```

    1.2 逻辑
        每间隔一段时间记录一次 -- 10s
        or 事件码发生改变就记录一次

    1.3 策略
    `running_log_t` 的数据不够 128Byte, 记录数据的时候，先填充数据结构体，然后再把数据结构体的数据内容通过 `memcpy` 拷贝到 temp[128] 临时数组，然后再把 temp[128] 的数据写到运行日志文件。

    temp[128] 放大每次储存的数据区作用： 为后面版本迭代更多数据做预留
